Cymatics.art

A digital cymatics playground inspired by FuzzyGraph. Arrange resonators, choose a reflecting boundary, and explore their interference. Technically, this is not really cymatics, but rather a way of playing with wave interference patterns with boundaries similar to cymatics.

Resonators

Basic mode distributes sources evenly around the center (a single source sits at the origin). Advanced mode lets you add, edit, and remove individual sources with their own X/Y, amplitude, frequency, phase multiplier, phase offset, and waveform. The resonators_list stores these settings. Resonator Rotation rotates the entire layout around the origin in both modes; Advanced X/Y values remain the coordinates before that rotation. Switching modes preserves your sources; changing a Basic resonator control regenerates a uniform arrangement.

Frequency is cycles per graph unit. The phase of each wave is phase × phase_multiplier + phase_offset. Sinc uses FuzzyGraph’s radial sine divided by radial distance, with a finite core at the source. The other waveforms have constant amplitude.

Boundaries and reflections

Boundary radius is the distance from the center to each vertex. Rectangle uses its Width and Height instead of Radius. Boundary Rotation rotates the walls around the origin independently of the resonators and view. Waves reflect specularly at the walls and interfere with the direct waves using the same combine operator. The field is clipped outside the boundary. None shows unbounded waves.

Named polygons use paths with up to two reflections. Circle uses a 64-sided approximation with one reflection; custom polygons above 12 sides also use one reflection. This finite image-source model is an artistic wave model, not an exact vibrating-plate or infinite-reverberation solver.

Binary Split means two parallel, infinite walls at x = −radius and x = +radius. Each reflection preserves amplitude and phase. Sources outside a boundary are marked in red in the position preview; move them inside for an enclosed-source pattern.

Operators fold left in list order: each direct wave, then its valid reflections. Subtraction, multiplication, and division apply to reflected contributions too. Near-zero divisors are bounded to keep rendering finite.

Phase and view

The app starts playing. The canvas Pause button selects Fixed phase; Play selects Animated phase. The button and sidebar radio buttons stay synchronized.

Animated phase visits 2π × k / steps, for k from 0 to steps − 1, at the selected number of steps per second. It wraps without duplicating 0 and 2π. Fixed phase accepts radians from 0 to 2π. Animation pauses while a dialog is open or the tab is hidden.

Drag to pan. Scroll or pinch to zoom. + and − zoom around the center; Home fits the boundary, and Go to sets an exact center and view height. Rotation is in degrees. Fuzzy Level uses the same power transfer as FuzzyGraph; zero highlights near-zero wave values. Min Override defaults to zero and stays enabled when other settings change. Max Override defaults to 1 and is cleared when wave, boundary, phase-step, or view settings change, or when a fixed phase is edited. With Max Override off, the color scale uses the current frame’s sampled maximum. Animation, playback controls, and color adjustments preserve a manually set maximum.

Color and files

Background Color sets the area outside the boundary, including saved images. The color maps and color adjustments come from FuzzyGraph. Color Start is an offset in color-map entries; Color Cycles repeats the map. Hue Shift is in degrees; Saturation and Luminosity are percentage adjustments.

Save offers Image (PNG), Video, and JSON from the same dialog. Video provides resolution, FPS, and phase-cycle controls; cycle length follows Phase Steps / Speed, rounded to whole video frames. MP4 is used when recording is supported, with WebM as a fallback. Video frames use equal phase increments and fixed timestamps, so rendering speed does not change playback timing. The final frame is one phase step before the first, without duplicating the endpoint. Older browsers use live recording as a fallback. Keep this tab visible while exporting. Cancel export, Escape, or closing the dialog stops recording without downloading a partial file. Video exports preserve the main view and its phase. Integer phase multipliers repeat cleanly over each global phase cycle. PNG exports include embedded settings; videos do not. When a closed boundary is fully visible, Crop to boundary exports its tight bounds, with transparency outside the shape for PNG and Background Color outside the shape for video. Width and Height stay linked to the boundary aspect ratio. Infinite Binary Split walls and None cannot be cropped. Open restores saved PNG images or JSON configurations. Share makes a link for https://cymatics.art. Download saves this entire app as one HTML file that works offline, including your current pattern. No sign-ups or tracking.
